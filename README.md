# t4sg-unicef-fall-2026

Testing whether AI chatbots give accurate UNICEF statistics, compared against official UN/UNICEF data as the truth.

## Folders
- `prompts/` – questions we ask the models
- `data/` – ground truth pulled from the UNICEF SDMX API
- `pipeline/` – code that runs the tests
- `results/` – model answers and scoring
- `notes/` – meeting notes, hypotheses, findings
